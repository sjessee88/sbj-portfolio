VESSEL CREW LOG

A digital solution for managing crew data across more than 100 vessels at American Commercial Barge Line.

Project Overview

The Vessel Crew Log is a custom Power Platform solution that replaced the deprecated crew log software at American Commercial Barge Line (ACBL). It allows vessel captains and dispatchers to log, review, and confirm employee assignments in real time using Power Apps, Power Automate, and SharePoint integration.

Tools & Technologies

  • Microsoft Power Apps (Canvas App)
  • Power Automate for workflow automation
  • SharePoint Lists for structured data storage
  • Power BI for data visualization
  • UKG Workforce Management API integration
